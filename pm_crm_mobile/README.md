# PM CRM Mobile (Flutter)

Мобильная версия CRM дистрибьютора PM International (Android, .apk).
Логика зеркалирует десктопную версию: те же статусы (включая
«Подписан в глубь»), та же воронка касаний, тёплая палитра.

## Возможности

- **Контакты** — список, поиск по имени/телефону, фильтр по статусу,
  добавление/редактирование/удаление, **импорт CSV из Telegram**
  (автоподбор колонок, пропуск дубликатов).
- **Воронка (в карточке контакта)** — касания «Созвон/Встреча»,
  результат «Подписался / Подписался в глубь / Не подписался /
  Перенесено», дата следующей встречи, договорённости, комментарий;
  статус контакта обновляется автоматически; история — обратная
  хронология с удалением.
- **Напоминания** — встречи, запланированные на сегодня.
- **Статистика** — встречи сегодня/всего, подписки и «в глубь», отказы,
  конверсия, индикатор нормы, рекомендация при низкой конверсии.
- **Помощь** — реферальная ссылка (сохранить/копировать/открыть),
  справочник возражений с отработкой (редактирование/добавление/
  удаление/копирование), свои важные ссылки (копирование/открытие/
  удаление).

Данные хранятся локально в SQLite (`sqflite`) на устройстве; интернет
нужен только для открытия ссылок в браузере.

## Структура

```
lib/
├── main.dart                    # точка входа
└── src/
    ├── models.dart              # статусы, результаты, модели, цвета
    ├── db.dart                  # SQLite: contacts / touches / settings
    ├── csv_import.dart          # импорт CSV (Telegram)
    ├── utils.dart               # даты, телефоны, буфер обмена
    ├── theme.dart               # тёплая палитра + общие элементы
    └── screens/
        ├── home_screen.dart     # нижняя навигация
        ├── contacts_screen.dart # контакты + импорт
        ├── contact_edit_screen.dart
        ├── contact_detail_screen.dart  # воронка касаний
        ├── reminders_screen.dart
        ├── stats_screen.dart
        └── help_screen.dart
```

## Сборка .apk через GitHub Actions (рекомендуется)

1. Загрузите проект в репозиторий GitHub (вся папка `pm_crm_mobile`
   и файл `.github/workflows/build-apk.yml` в корне).
2. Откройте **Actions → Build APK → Run workflow** (или просто
   запушьте изменения в `main`).
3. После успешного прогона откройте артефакт **pm-crm-apk** и скачайте
   `app-release.apk`.
4. Установите apk на телефон (разрешите установку из неизвестных
   источников).

Workflow сам выполняет `flutter create --platforms=android`, `pub get`,
`analyze`, `test` и `flutter build apk --release`.

## Локальная сборка

Нужны Flutter SDK (stable) и Android SDK (Android Studio).

```bash
cd pm_crm_mobile
flutter create --platforms=android --org com.pmint.crm .
flutter pub get
flutter analyze
flutter test
flutter build apk --release
# APK: build/app/outputs/flutter-apk/app-release.apk
```

Для установки на устройство: `flutter install` (или скопировать apk).

## Примечания

- Фоновые push/локальные уведомления о встречах в мобильной версии пока
  не реализованы (потребуется плагин локальных уведомлений и разрешение
  на фоновую работу). Список встреч на сегодня — во вкладке «Напоминания».
- Сборка Android выполняется в CI/локально; в репозиторий папка `android/`
  не входит (генерируется командой `flutter create`).
